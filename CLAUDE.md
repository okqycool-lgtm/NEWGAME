# CLAUDE.md

Cyber Heist: a Three.js + Vite parkour runner. See README.md for layout, controls and tests.

- `npm run dev`, `npm run build`; `PW=$(npm root -g)/playwright npm test` with the dev server on port 5173.
- Game code is in `src/`. Level geometry is procedural (`world.js`, `world2.js`); modelled assets come from
  `public/assets/*.glb` through `src/assets.js`, and every use keeps a procedural fallback.
- Art is generated by `blender/build_*.py` on top of `blender/lib.py` (Blender 5.3 via the `bpy` wheel in
  `tools/.venv`; see README "Art pipeline"). Never hand-edit the GLBs; change the script and rebuild.
- Blender agent skills live in `blender-skills/skills/<name>/SKILL.md`. Read `blender-core` first, then the
  relevant skill, before writing `bpy` code. `BLENDER_EXE=tools/blender` runs the skill scripts headless.
- Conventions: 1 unit = 1 m; models face Blender -Y (three.js +Z, toward the approaching runner), except
  the runner and getaway vehicles which face +Y (the direction of travel). One palette material per GLB,
  AO in vertex colours, `_LOD1` nodes for distant use.
